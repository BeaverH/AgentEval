# v0.2.24 发布验证

本版提供正式 UI 可调用的 NeMo/F5 集成 API 契约，保留 V3 快速部署 UI 和独立 V2 Mock。新增离线 Swagger、API 列表、单项连接测试、默认 NeMo TLS 跳过及脱敏错误原因链。

功能验证：1,176 项 control 测试通过、9 项跳过；TypeScript 与生产构建通过。单项测试覆盖 NeMo URL/PAT、PostgreSQL/MariaDB SELECT 1 及连接清理、F5 URL/Token。测试不保存配置、不创建业务资源。已用本地 NeMo/MariaDB 真实配置验证 URL、Token、数据库三个测试均成功；未配置时文档、V3 与 Mock 均可访问。

真实 HTTPS 测试验证 NeMo 默认跳过、自定义 CA 验证、非 NeMo 请求仍验证；F5 与 NeMo 共用网关且路径重叠时，也不会继承 NeMo TLS 跳过。错误保留 HTTP 状态和受限原因链，过滤凭据、SQL、证书、原始 HTML 和任意异常属性。上游错误正文读取有超时与大小上限。

接口模型由处理请求所用 Zod schema 生成。Swagger 静态资源打入镜像，不调用外部 CDN 或 validator。外部 UI 使用同域 `/api`，角色切换、revision、幂等 requestId、advance/reconcile 和 HTTP 200 内任务失败的处理均在 `docs/integration-api.md` 中说明。

正式镜像发布流程验证 mock/live/随机 OCP UID 启动、源码与 Chart 完整性、共享配置卷读写、Swagger 资产、默认与 verify TLS 的 Helm 渲染，以及 16 类真实配置故障下 Mock/UI 继续可用。逐项结果以本版本 Actions、`isolation-test-results.json`、离线包 `manifest.json` 为准。

没有新增必填连接值；Secret 默认仍为 tali 中的原始 NeMo PAT 与完整数据库 URL。源码、镜像和离线包排除本地测试凭据和已保存连接配置。

验收边界：本地 NeMo/MariaDB 已连通；F5 仍为契约测试，目标内网 F5、OCP 网关/存储/权限、模型/Runner 与真实发布流程需要部署环境验收。NeMo TLS 默认跳过仅适用于默认 V3 演示；可显式选择 verify，F5/DB 不受影响。
