# v0.2.25 发布验证

本版更新 V2 Mock Measure：CU 扫描概览、Guardrail/Policy/Agent/Scan 下钻、反馈表单、Passed/Blocked 颜色区分与跳转回顶部。导航支持刷新恢复、浏览器前进后退，以及来源、筛选和分页恢复。Breach Monitor 入口隐藏。

Tech Measure 参考白板蓝色流程，提供系统性能、日/月趋势对比、模型使用、Runner、资源健康及分类反馈查看和关闭预览。指标、图表和记录均为明确标识的 placeholder；关闭预览只保留当前页面输入，不创建模拟反馈或成功关闭记录。CU 使用已有 V2 示例及缺失字段 placeholder。

本地验证涵盖 Measure 导航、存储失败、重复反馈保护、角色入口、占位流程无网络请求与无持久化写入。全量测试：200 个测试文件通过、3 个跳过；1194 项测试通过、9 项跳过。生产构建和 TypeScript 检查通过。浏览器已验证 CU 下钻/刷新/返回，Tech 趋势刷新与反馈关闭预览。

发布镜像由标签对应源码构建，沿用 CI 的 mock/live/随机 OCP UID 启动、源码包校验、Helm 渲染及 16 类真实集成故障隔离验证。最终测试数量和发布产物以 Release 附件与 Actions 结果为准。

升级只需使用 0.2.25 镜像与 Chart，无新增必填配置或数据迁移。V3 集成能力及配置策略沿用 0.2.24；F5、目标内网 OCP 和真实运行时仍需部署环境验收。
